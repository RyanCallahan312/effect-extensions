# Runnable examples

Both apps use the local package's built exports and the same Vite plugin setup as an application consumer.

From the repository root:

```sh
bun install
bun run build
```

Then start either app:

| App | Command from the repository root | URL | Demonstrates |
| --- | --- | --- | --- |
| [Basic](basic) | `bun run --cwd examples/basic dev` | http://localhost:3000 | Raw Schemas, Effect handlers, SSR, redirects, and native environment helpers |
| [Services](services) | `bun run --cwd examples/services dev` | http://localhost:3001 | ManagedRuntime, service Layers, mutations, public errors, and sanitized defects |

Use `preview` instead of `dev` to serve the production build. `bun run dev` starts both apps and the package's TypeScript watcher together. Rebuild after package changes when using `preview`.

Each app is a private workspace with its own standard Vite config and TypeScript config. `src/routeTree.gen.ts` is generated by Start during dev/build. The examples use `workspace:*` because this package is developed in this repository.

The basic app's **Composition** selector compares `gen`, `pipe`, `flow`, `Effect.fn`, and do notation. The services app demonstrates piped service work and optional `catchTag` recovery. Read the [composition guide](../packages/tss-effect-serverfn/docs/composition.md) alongside the source.

## Browser tests

```sh
bunx --no-install playwright install chromium
bun run test:e2e
```

The suite builds the apps and starts its own servers on ports 4310–4313. It exercises each app in Chromium against both Vite dev and production preview. See [E2E details](../e2e/README.md) for coverage and debugging.
